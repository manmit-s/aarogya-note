# Empirical Evaluation & Benchmarks

This document outlines the evaluation methodology, dataset composition, scoring rubrics, and latency measurements for **AarogyaNote**.

---

## Evaluation Dataset

AarogyaNote was evaluated using a controlled benchmark suite of **four synthetic outpatient consultation recordings** generated using Gnani Timbre TTS from curated clinical dialogue scripts:

| Scenario | Audio File | Audio Duration | Primary Clinical Focus |
|---|---|---:|---|
| **Viral Fever & Body Ache** | `transcript1.wav` | 60.5s | Acute febrile illness, temperature tracking, antipyretics |
| **Gastritis & Functional Dyspepsia** | `transcript2.wav` | 62.1s | Epigastric burning, postprandial distress, PPI therapy |
| **Upper Respiratory Infection** | `transcript3.wav` | 71.4s | Sore throat, nasal congestion, antihistamines, gargles |
| **Knee Osteoarthritis & Vitamin D** | `transcript4.wav` | 64.8s | Bilateral knee pain, mobility issues, cholecalciferol |

> [!NOTE]
> **Important Limitation:** These are synthetic demonstration recordings created from controlled scripts, not real patient consultations. They serve to benchmark extraction accuracy and latency under repeatable conditions, not as proof of independent diagnostic safety in clinical practice.

## 1. Clinical Extraction Field Agreement

The structured output generated by Groq `openai/gpt-oss-120b` was evaluated against manually prepared gold-standard reference notes across ten clinical and prescription categories:

| Clinical Field | Agreement Score | Performance Notes |
|---|---:|---|
| **Chief Complaint** | **100.0%** | Exact symptom identification across all 4 scenarios |
| **Examination Findings** | **100.0%** | Successfully isolated clinician observations from patient statements |
| **Medicine Duration** | **92.0%** | High fidelity on treatment courses (e.g., *3 days, 1 month*) |
| **Medicine Dosage** | **83.0%** | Accurate strength extraction (e.g., *650 mg, 40 mg, 60,000 IU*) |
| **Follow-Up Schedule** | **75.0%** | Preserved clinician review timelines and escalation cues |
| **Medicine Name** | **75.0%** | Accurately extracted prescribed medications in 3 of 4 cases |
| **Provisional Diagnosis** | **75.0%** | Diagnostic assessment extracted with appropriate clinical uncertainty |
| **Advice & Precautions** | **62.0%** | Captured dietary instructions, hydration, and rest guidance |
| **History of Present Illness (HPI)** | **50.0%** | Chronology maintained; partial detail on secondary triggers |
| **Medicine Frequency** | **25.0%** | Omitted specific timing nuance in conversational Hindi |
| **Overall Macro Field Agreement** | **73.8%** | **Strong structured extraction baseline** |

### Scoring Rubric & Interpretation
- **1.0**: Exact or near-exact semantic match to the reference gold note.
- **0.5**: Partially correct or incomplete field extraction.
- **0.0**: Missing, incorrect, or hallucinated information.
- The overall macro score is the unweighted average across all evaluated fields.
- **Key Findings**: Medicine frequency and HPI were weaker than chief complaints and physical examination findings. In outpatient workflows, clinicians must always review the generated prescription card before signing off.

## 2. Speech Recognition Evaluation

Prisma v2.5 transcripts were compared against reference scripts using standard word and character error metrics computed with `jiwer`:

| Metric | Aggregate Result | Notes |
|---|---:|---|
| **Average Raw WER** | **103.1%** | Word Error Rate (unweighted macro average) |
| **Average Raw CER** | **85.0%** | Character Error Rate (unweighted macro average) |

### Per-Scenario Raw WER
| Consultation Scenario | Raw WER |
|---|---:|
| Viral Fever & Body Ache | 104.2% |
| Gastritis & Functional Dyspepsia | 106.5% |
| Upper Respiratory Infection | 103.0% |
| Knee Osteoarthritis & Vitamin D | 98.8% |

### The Script-Normalization Effect
Gnani Prisma v2.5 outputs native **Devanagari script** for Hindi speech (e.g., `नमस्ते, बताइए क्या प्रॉब्लम है`), whereas the reference scripts use **Romanized Hinglish** (e.g., `Doctor: Namaste, bataiye kya problem hai`). 

Direct string-level comparison between different scripts mathematically inflates WER and CER well above 100%. Raw scores overstate lexical error where the underlying words are semantically identical across scripts. Downstream clinical extraction scored **73.8%**, indicating that semantic comprehension remained robust despite raw script divergence.

## 3. Latency Benchmarks

The following measurements reflect sequential live cloud API round-trips:

| Pipeline Stage | Mean Latency | Observed Range | Description |
|---|---:|---:|---|
| **Gnani Prisma v2.5 (STT)** | **3.29s** | 1.33s – 8.86s | Sequential chunked acoustic speech recognition |
| **Groq LPU Extraction** | **3.02s** | 2.12s – 3.92s | Strict JSON schema structured parsing |
| **Combined Core Pipeline** | **6.31s** | 3.71s – 12.79s | End-to-end: audio ingestion to structured note |
| **Gnani Timbre v2.5 (TTS)** | **3.50s** | 2.80s – 4.20s | Spoken summary synthesis (`Nalini` voice) |

*Tested on Python 3.11 with FastAPI backend over broadband internet connection.*
